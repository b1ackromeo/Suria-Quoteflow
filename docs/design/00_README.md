# QuoteFlow Design System v1

This folder defines the UI/UX direction for QuoteFlow.

QuoteFlow should not chase decorative dashboard trends. It should combine:

```text
Figma-style component discipline
+ Dribbble-level polish
+ real operations workflow clarity
+ Exabytes/Plesk shared-hosting-safe implementation
```

## Required reading for UI work

For any UI, UX, Blade, CSS, dashboard, document-workbench, form, or copywriting task, Codex should read:

1. `AGENTS.md`
2. the assigned file in `docs/codex-tasks/`
3. the relevant files in this folder

## North-star experience

Every screen should answer, in this order:

```text
What is this record or area?
What state is it in?
What needs attention?
What is the next action?
What blocks that action?
Where is the evidence?
What happened before?
```

## Core UI rule

The app should feel like an experienced operations coordinator:

```text
This invoice is uploaded.
OCR found draft details.
You still need to verify the total.
After that, submit it for approval.
Payment is locked until matching is complete.
```

Avoid screens that feel like:

```text
Here are many cards and buttons. Work it out yourself.
```
